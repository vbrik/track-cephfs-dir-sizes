# Code
- Ensure code does not get out of sync with comments and docstrings, documentation.
- Structure code for human readability.
- Make comments concise and to the point.
- Write function doc strings except for trivial functions.
- Prefer to use the latest available features, syntax, modules/libraries of whatever language you use if it improves code.
- Assume the reader is an expert in whatever language you are using.

# Testing
- Add unit tests for new or changed functionality
- If it makes sense, add unit tests when the way of how components interact changes
- Run unit tests to check your work
- Test corner conditions
